How it works

Three steps, nothing to set up

  1. 1

    Install

    curl -fsSL https://{{domain}}/install.sh | sh

    One file, no dependencies. It goes in your home folder and needs no admin rights.

  2. 2

    Run

    $ carrel doctor
java   found
g++    found

$ carrel
ready on http://127.0.0.1:7777

    Your browser opens. The server only listens on your own computer.

  3. 3

    Practise

    pick a problem
write Java or C++
press Submit

    Your code saves as you type. Close the tab and pick up where you left off.
