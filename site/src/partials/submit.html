What a submit does

Every submit is a fresh test

Random cases come from a seeded generator that already knows the answer, so Carrel can check yours without any AI. If a case fails, the seed lets you run it again.

  1. 1

    Compile once

    Your code is built one time. Every case then runs in the same process.

  2. 2

    5 fixed cases

    The examples and the edge cases the problem author picked.

  3. 3

    50 random cases

    New inputs from a seeded generator that knows the right answer.

  4. 4

    One clear result

    Pass or fail, the failing case, and the seed to repeat it.
