You are given the root of a binary search tree with different values and a number `k`. Return the `k`-th smallest value, counting from 1.

Visiting a search tree left, node, right gives its values in increasing order. Stop as soon as you have counted `k`.

## Constraints

- 1 ≤ k ≤ number of nodes ≤ 10⁴
- −10⁵ ≤ value ≤ 10⁵
