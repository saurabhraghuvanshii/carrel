Two words use the same letters if you can rearrange the letters of one to spell the other, using each letter exactly as many times as it appears. Given two words made of lowercase letters, return `true` if they use the same letters and `false` otherwise.

## Constraints

- 1 ≤ length of each word ≤ 5 × 10⁴
- Only the letters `a` to `z`

## Follow-up

How would your answer change if the words could hold any Unicode character?
