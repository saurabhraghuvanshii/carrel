You are given the roots of two binary trees. Return `true` if they have the same shape and the same value in every matching node, and `false` otherwise.

Two trees are the same if their roots match and their left subtrees are the same and their right subtrees are the same. That sentence is already the recursive solution.

## Constraints

- 0 ≤ number of nodes in each tree ≤ 10⁴
- 0 ≤ value ≤ 10⁴
