You get the first node of a singly linked list. Each node holds a whole number and a link to the next node, and the last node links to nothing. Turn the list around so it runs from the old last node back to the old first node, and return the node that is now first.

Try to do it by changing the links between the nodes you already have, without making new nodes.

## Constraints

- 0 ≤ number of nodes ≤ 10⁴
- −1000 ≤ value ≤ 1000
- An empty list is given as no node at all (`null` in Java, `nullptr` in C++)
