Given `n`, return every string of `n` opening and `n` closing round brackets that is balanced: read from the left, you never close more brackets than you have opened. Return them in any order.

Do not build all strings and filter them. Add `(` while you have some left, and add `)` only while fewer have been closed than opened.

## Constraints

- 1 ≤ n ≤ 9
