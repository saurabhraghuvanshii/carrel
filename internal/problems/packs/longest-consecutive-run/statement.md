You are given an unsorted list of whole numbers. Find the longest run of values that follow each other with no gaps, such as 4, 5, 6, 7, using values from the list in any order. A value that appears more than once counts once.

Return the length of that run, or 0 if the list is empty. Aim for a solution that does not sort the list.

## Constraints

- 0 ≤ length ≤ 10⁴
- −10⁹ ≤ value ≤ 10⁹
