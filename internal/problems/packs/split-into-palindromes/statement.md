You are given a word. Return every way to cut it into pieces, keeping the letters in order, so that each piece reads the same forwards and backwards. Return the ways in any order; inside a way, the pieces are in word order.

Try every first piece that reads the same both ways, then cut the rest the same way.

## Constraints

- 1 ≤ length ≤ 12
- Only `a` to `z`
