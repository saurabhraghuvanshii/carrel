You are given a word whose letters are all different. Return every subset of its letters, including the empty one, as a string with the letters in the same order as in the word. Return the subsets in any order.

For each letter there are two choices: take it or leave it. That gives 2ⁿ subsets.

## Constraints

- 1 ≤ length ≤ 10
- Only `a` to `z`, all different
