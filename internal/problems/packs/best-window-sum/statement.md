You are given a list of whole numbers and a window size `k`. Look at every stretch of exactly `k` neighbouring values and return the largest sum among them.

Slide the window instead of adding it up again each time: when it moves one step right, one value leaves on the left and one enters on the right.

## Constraints

- 1 ≤ k ≤ length ≤ 10⁴
- −10⁴ ≤ value ≤ 10⁴
