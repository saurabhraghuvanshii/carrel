You are given a list of lowercase words. Put words that use the same letters, each letter the same number of times, into one group. Return the list of groups. Every word goes into exactly one group, and if a word appears more than once, keep every copy.

You may return the groups in any order, and the words inside a group in any order.

## Constraints

- 1 ≤ number of words ≤ 5000
- 1 ≤ length of a word ≤ 8
- Only the letters `a` to `z`

## Follow-up

Sorting each word gives a key in O(L log L). Can you build a key in O(L) instead?
