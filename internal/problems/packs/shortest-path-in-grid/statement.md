You are given a grid of `0` (open) and `1` (wall). Moving up, down, left or right through open cells, find the shortest path from the top-left cell to the bottom-right cell. Return the number of cells on it, counting both ends, or −1 if there is no path (including when either end is a wall).

Breadth-first search finds shortest paths when every step costs the same.

## Constraints

- 1 ≤ rows, cols ≤ 60
- Every cell is 0 or 1
