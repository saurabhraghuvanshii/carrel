You are given a list of whole numbers and a target. Find every triple of values, taken from three different positions, that adds up to the target.

List each triple of values once, even if the same values can be picked from different positions. Return the triples in any order, and the values inside a triple in any order.

## Constraints

- 3 ≤ length ≤ 500
- −10⁵ ≤ value ≤ 10⁵
- −3 × 10⁵ ≤ target ≤ 3 × 10⁵

## Follow-up

After sorting, fix the first value and look for the other two as in "Pair in a sorted list". How do you skip repeated triples without a set?
