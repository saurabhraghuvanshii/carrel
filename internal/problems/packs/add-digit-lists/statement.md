Two whole numbers are stored as linked lists of digits, lowest digit first: 243 is the list 3 -> 4 -> 2. Return their sum as a new list in the same form.

The numbers can have thousands of digits, far too many for any integer type. Add digit by digit and carry, as on paper.

## Constraints

- 1 ≤ length of each list ≤ 10⁴
- Every value is a digit from 0 to 9
- No number has a leading zero, except the number 0 itself
