You are given the root of a binary tree. Return the number of nodes on the longest path between any two nodes. A path goes along the links between parents and children and never visits a node twice; it does not have to pass through the root. An empty tree has 0.

The longest path through a node uses the depth of its left subtree and the depth of its right subtree, as in "Depth of a binary tree". Compute depths and the best path in the same pass.

## Constraints

- 0 ≤ number of nodes ≤ 10⁴
- −100 ≤ value ≤ 100
