Given a whole number `n`, return every string of `n` characters made of `0` and `1` in which no two `1`s are side by side. Return them in any order.

Build the strings one character at a time. You can always add a `0`; add a `1` only if the last character was not a `1`.

## Constraints

- 1 ≤ n ≤ 16
