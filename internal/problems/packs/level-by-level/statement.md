You are given the root of a binary tree. Return its values row by row, from the top row down, and from left to right inside each row.

Use a queue. Before handling a row, note how many nodes are in the queue: exactly those belong to the row.

## Constraints

- 0 ≤ number of nodes ≤ 10⁴
- −1000 ≤ value ≤ 1000
