You are given the root of a binary tree with different values, and two different values `p` and `q` that are both in the tree. Return the value of their lowest common ancestor: the deepest node that has both `p` and `q` below it or is one of them. A node counts as an ancestor of itself.

This is any binary tree, not a search tree, so values do not tell you which way to go.

## Constraints

- 2 ≤ number of nodes ≤ 10⁴
- −10⁵ ≤ value ≤ 10⁵, all different
