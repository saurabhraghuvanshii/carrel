You are given the first nodes of two linked lists, each sorted from smallest to largest. Join them into one sorted list by changing the links between the nodes you have, and return its first node. Either list may be empty.

A placeholder node in front of the result saves you from treating the first node as a special case.

## Constraints

- 0 ≤ length of each list ≤ 10⁴
- −1000 ≤ value ≤ 1000
