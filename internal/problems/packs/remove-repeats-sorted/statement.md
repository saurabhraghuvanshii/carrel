You are given a list of whole numbers sorted from smallest to largest. Change the list in place so that each value appears once, keeping the order, and return how many values are left, `k`.

The first `k` positions must hold the kept values. Whatever is after them does not matter. Use only a fixed amount of extra memory: one pointer reads, another writes.

## Constraints

- 0 ≤ length ≤ 10⁴
- −10⁵ ≤ value ≤ 10⁵
- The list is sorted from smallest to largest
