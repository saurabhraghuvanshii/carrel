You are given a list of whole numbers and a number `k`. Return the `k` values that appear most often in the list.

The tests are chosen so the answer is clear: every value in the answer appears more often than every value left out. Return the values in any order.

## Constraints

- 1 ≤ length ≤ 2 × 10⁴
- −10⁴ ≤ value ≤ 10⁴
- 1 ≤ k ≤ number of different values

## Follow-up

Sorting all the counts costs O(m log m) for m different values. Can you do better when k is small, or without comparing counts at all?
