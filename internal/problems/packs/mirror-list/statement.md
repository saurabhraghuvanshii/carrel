You are given the first node of a linked list. Return `true` if its values read the same from front to back as from back to front, and `false` otherwise.

Copying the values into an array works. Try it with a fixed amount of extra memory: find the middle as in "Middle of a linked list", reverse the second half as in "Reverse a linked list", then compare the two halves.

## Constraints

- 1 ≤ length ≤ 10⁴
- 0 ≤ value ≤ 1000
