You are given a list of whole numbers. Return `true` if some value appears in the list more than once, and `false` if every value is different.

## Constraints

- 1 ≤ length ≤ 10⁴
- −10⁹ ≤ value ≤ 10⁹

## Follow-up

Sorting the list first would also work. What does each approach cost in time and in extra memory?
