You are given a list of positive whole numbers and a target. Return the length of the shortest stretch of neighbouring values whose sum is at least the target, or 0 if no stretch reaches it.

Because every value is positive, growing the window only raises the sum and shrinking it only lowers it.

## Constraints

- 1 ≤ length ≤ 10⁴
- 1 ≤ value ≤ 10⁴
- 1 ≤ target ≤ 10⁹
