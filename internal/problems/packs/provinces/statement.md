You are given an undirected graph with `n` nodes numbered 0 to `n − 1` and a list of edges. A connected group is a set of nodes that can all reach each other. Return the number of connected groups.

Start a search from every node not yet visited; each new start is a new group.

## Constraints

- 1 ≤ n ≤ 10⁴
- 0 ≤ number of edges ≤ 10⁴
- Edges may repeat
